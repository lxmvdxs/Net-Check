# NetCheck: быстрая диагностика интернета для хелпдеска

[English](README.md) | **Русский**

Небольшая утилита для Windows. По двойному клику открывает несколько окон `cmd`, в каждом своя диагностическая команда (`ping`, `tracert`, `curl` и т. д.). Окна автоматически расставляются сеткой и не накладываются друг на друга.

Сценарий использования: у сотрудника пропал или тормозит интернет при подключении **по Ethernet-кабелю**. Он запускает `NetCheck.exe`, а хелпдеск по живым окнам сразу видит, где проблема: до шлюза, до внешнего мира, в DNS и т. д.

По умолчанию открываются 4 окна:

| Окно | Команда | Что показывает |
|------|---------|----------------|
| Ping Google DNS | `ping 8.8.8.8 -t` | есть ли связь с интернетом |
| Ping Gateway | `ping {GATEWAY} -t` | есть ли связь с роутером/коммутатором |
| Tracert Google | `tracert 8.8.8.8` | на каком узле обрывается маршрут |
| External IP | `curl ipinfo.io` | внешний адрес и провайдер |

Метка `{GATEWAY}` автоматически заменяется на IP шлюза по умолчанию. Если шлюз не найден (кабель не подключён, DHCP не выдал адрес), в окне будет `GATEWAY_NOT_FOUND`.

## Требования

- Windows 10 / 11
- [Go](https://go.dev/dl/) (только на машине хелпдеска, для сборки)
- VS Code или любой текстовый редактор
- На ПК пользователя ничего устанавливать не нужно: достаточно одного `.exe`

## Быстрый старт

1. Скачайте репозиторий (`git clone` или **Code → Download ZIP**, затем распакуйте).
2. Откройте папку в VS Code.
3. Отредактируйте список команд в `main.go` (см. ниже).
4. Запустите `build.bat` (двойной клик). В папке появится `NetCheck.exe`.
5. Скопируйте `NetCheck.exe` на ПК пользователя и создайте ярлык на рабочем столе.
6. При проблеме пользователь просто дважды кликает по ярлыку.

Сборка вручную:

```bash
go build -ldflags="-H=windowsgui -s -w" -o NetCheck.exe
```

Ключ `-H=windowsgui` убирает служебное окно самой программы, остаются только окна с командами.

## Как добавить или изменить команды

Откройте `main.go` и найдите список `terminals`. Каждая строка - одно окно:

```go
{"Название окна", "команда"},
```

Внизу списка есть готовые примеры в комментариях. Уберите `//` в начале строки и впишите нужную команду или IP:

```go
// {"Ping server", "ping 10.0.0.1 -t"},       // впишите нужный IP
// {"Tracert server", "tracert 10.0.0.1"},    // впишите нужный IP
// {"DNS check", "nslookup google.com"},
// {"Network config", "ipconfig /all"},
```

Правила:

- **Каждая строка должна заканчиваться на `},`** (закрывающая фигурная скобка и запятая). Пропущенная запятая - самая частая ошибка сборки (`unexpected newline in composite literal`).
- Используйте обычные прямые кавычки `"`, а не изогнутые `“ ”` и не «ёлочки» `« »` (они появляются при копировании из Word или мессенджеров).
- Название окна не должно содержать символы `&`, `|`, `"`.
- Если в самой команде нужны `&` или `|`, экранируйте их: `^&`, `^|`.
- Количество окон не ограничено. Раскладка подстраивается сама: 4 окна дают сетку 2×2, 6 окон 3×2, 9 окон 3×3.
- Окна не закрываются после завершения команды, результат остаётся на экране.

## Как это работает

1. Определяет шлюз по умолчанию через `route print` (не зависит от языка Windows).
2. Запускает каждую команду в отдельном окне через `conhost.exe cmd.exe /k`. Это классические окна консоли, они не сливаются во вкладки Windows Terminal на Windows 11.
3. Находит каждое окно по уникальной метке в заголовке и двигает его в свою ячейку сетки по рабочей области экрана (без панели задач).

## Известные особенности

- Тестируйте собранный `.exe`, а не `go run` из терминала VS Code: поведение окон может отличаться.
- У окон Windows 10/11 есть невидимая рамка, поэтому между окнами возможен зазор или перекрытие в несколько пикселей.
- Антивирусы иногда подозрительно относятся к неподписанным `.exe`, которые запускают `cmd`. Если так, добавьте файл в исключения или подпишите его сертификатом организации.
- `curl` встроен в Windows 10 (1803) и новее. На более старых системах команда не сработает.
